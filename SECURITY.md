# Security Policy

Healthy keeps people's health records, so we take security reports seriously and thank everyone who sends one.

## Reporting a Vulnerability

Please report it privately, never in a public issue or pull request:

- Use [Report a vulnerability](https://github.com/DeividasK/healthy/security/advisories/new) on GitHub, or
- Email hello@usehealthy.app.

Tell us what you found, how to reproduce it and what it could expose. We reply within a week, keep you updated while we fix it, and credit you in the advisory unless you would rather stay anonymous.

## Scope

- The web app at usehealthy.app/a and the Android app, latest release
- The website and demo at usehealthy.app
- The Google token service in `workers/google-token`

Only the latest release gets security fixes.
